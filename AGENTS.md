# AGENTS.md

## Project Guidelines
- Use Playwright MCP first for frontend debugging. When you run into browser or UI issues, prefer the `playwright` and `playwright-interactive` skills before doing deeper investigation.
- Trigger `frontend-skill` when the task involves a visually strong landing page, website, app, prototype, demo, or game UI.
- Also trigger `frontend-skill` when the work depends on art direction, hierarchy, restraint, imagery, or motion more than on component count.
